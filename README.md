# 🌍 IMF Climate Insights

Este repositorio contiene un análisis reproducible basado en los indicadores del *IMF Climate Change Dashboard*.  
El objetivo es explorar la evolución de las emisiones de CO₂, la intensidad energética y otros factores relacionados con la sostenibilidad global, utilizando Python, visualización de datos y herramientas abiertas.

---

📘 **Estructura inicial**
- `data/` → fuentes y datos procesados  
- `notebooks/` → análisis exploratorio y visualizaciones  
- `src/` → scripts de carga, limpieza y visualización  
- `reports/` → documentación y entregables
- `results/` → figuras y tablas generadas  

---

🔗 **Fuentes de datos**
- [IMF Climate Change Dashboard](https://www.imf.org/en/Topics/climate-change/climate-change-dashboard)
